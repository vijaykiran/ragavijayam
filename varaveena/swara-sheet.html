Varaveena

Raga Mohanam (S R2 G3 P D2 — 28th melakarta janya) · Rupaka tala, chatusra jathi (drutam + laghu = 6 counts per avartana) · Sanskrit geetham on goddess Lakshmi · Sruti: Sa = C
How to read: each table = one line of the geetham = two avartanas (tala cycles), one swara per count. Rupaka as counted in class: drutam — count 1 clap, count 2 wave — then laghu — count 3 clap, counts 4–6 finger counts. The double border marks the boundary between the two avartanas.
Swaras: plain = middle octave · red with dot (ṡ ṙ ġ) = upper (tara) octave · , = hold previous note one count · – in the sahitya row = the syllable continues.
A geetham has no pallavi/anupallavi divisions — it is sung straight through, one flowing line after another, with no sangati variations.
